# Feature List
*/FeatureList ver 1.2.0:1.1.5/*

Feature List is a way to see all of the features that contains in this Swift package. A way to use this feature is by adding ```FeatureList()``` in to your code.

**Example**

*Must add the package first using this link (https://github.com/navaxichizann/SwiftCs.git)*

```
import SwiftUI
import SwiftCs

struct ContentView: View {
    var body: some View {
        FeatureList()
    }
}
